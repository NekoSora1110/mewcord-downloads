# Mewcord downloads 🐱

Download **Mewcord for Windows** from the [latest release](../../releases/latest).

* Windows 10 or 11 (64-bit). Installs just for you, no admin password needed.
* Windows may say *"Windows protected your PC"* because the app is new and not signed with a paid certificate yet.
  Click **More info → Run anyway**.
* Each release lists a SHA-256 checksum so you can check the file.

The app itself lives at **https://mewcord.onrender.com**. This repository only holds the download files.
